# Third-party notices and redistribution boundary

No third-party source code or baseline prediction data are vendored here.
The released model and calibration weights are project artifacts; the releasing
authors remain responsible for confirming that they have authority to publish
those weights.

The package imports Python dependencies installed by the user: NumPy, pandas,
SciPy, Matplotlib, PyYAML, PyTorch, and pytest. No source from those projects is
copied into this capsule. Users and redistributors must follow the licenses of
the exact versions they install.

The historical project repository does not currently contain a root license.
Accordingly, this capsule must not be described as open source until the
copyright holders add an explicit license. The included inference modules are
author-owned, inference-only reconstructions; no third-party model, baseline,
or dataloader source is vendored.

OSM biological data and baseline outputs are excluded. Their original dataset
and method licenses govern any redistribution.
